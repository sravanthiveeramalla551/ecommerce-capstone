# Nexa Store — Full-Stack Deployment & Project Architecture Capstone

## Included requirements

- Modular frontend architecture
- Client-side hash routing: Home, Products, About, Cart
- Product search and category filtering
- Shopping cart state
- localStorage cart persistence
- Dynamic DOM rendering
- Responsive CSS Grid/Flexbox layouts
- Lazy-loaded product images
- Optimized Unsplash image query parameters (`auto=format`, width and quality)
- Deployment configuration for Vercel and Netlify
- Semantic HTML and accessible labels

## Run locally

Open `index.html`, or use VS Code Live Server.

## GitHub

Create a repository such as:

`ecommerce-capstone`

Upload:
- index.html
- style.css
- app.js
- vercel.json
- netlify.toml
- README.md

## Deploy on Vercel

1. Push the project to GitHub.
2. Open Vercel and import the GitHub repository.
3. Keep Framework Preset as Other/Static.
4. Deploy.
5. Copy the generated public URL.

## Deploy on Netlify

1. Push the project to GitHub.
2. In Netlify, choose Add new project -> Import an existing project.
3. Select the repository.
4. Publish directory: `.`
5. Deploy.
6. Copy the generated public URL.

## Note

This capstone is a frontend production/deployment project. The checkout button is intentionally a demo action; a real payment backend can be connected later.
